# 主題與進階 CSS

[English](../themes.md) | **繁體中文**

使用頁首的調色盤按鈕（**主題風格**／Theme styles）選擇視覺風格。太陽／月亮選單則獨立控制深色、淺色或系統模式。切換主題不會變更服務、服務圖示顏色、排序、語言或存取權限。

## 功能適用版本

請使用版本說明包含獨立版面與背景圖片的發行版本，或建置對應的經審查原始碼。較早的 `1.0.1` 映像尚未提供這些功能；變更設定不會替舊映像加入新功能。詳見[部署](deployment.md)與[發行操作](releases.md)。任何主題設定都不會下載程式碼、字型或遠端主題網址。

## 色彩、版面與玻璃效果

**主題色彩**與**首頁版面**可分別選擇；每套色盤，包括自訂色彩主題，都能搭配任何版面。下表中相同的識別碼不代表兩者綁定。深色／淺色／**系統**、密度與玻璃效果也各自獨立；系統模式會跟隨裝置的配色偏好。

| 色盤                     | Preset ID      | 基礎圓角 | 陰影 |
| ------------------------ | -------------- | -------- | ---- |
| 未來玻璃（Future Glass） | `future-glass` | 16 px    | 柔和 |
| 石墨（Graphite）         | `graphite`     | 12 px    | 無   |
| 潮汐（Tide）             | `tide`         | 16 px    | 柔和 |
| 森序（Forest）           | `forest`       | 12 px    | 無   |
| 沙丘（Dune）             | `dune`         | 20 px    | 柔和 |

| 首頁版面 | Layout ID      | 特色                     |
| -------- | -------------- | ------------------------ |
| 分組卡片 | `future-glass` | 模組化分類與服務卡片     |
| 精簡索引 | `graphite`     | 精簡索引與橫向服務列     |
| 側邊標題 | `tide`         | 較寬螢幕在卡片旁顯示標題 |
| 分類書架 | `forest`       | 分組書架與精簡服務列     |
| 置中圖庫 | `dune`         | 置中圖庫與大型服務圖示   |

啟用玻璃效果時，所有色盤與版面都會透過半透明表面及背景模糊呈現底圖。停用玻璃、要求降低透明度、啟用強制高對比色彩，或瀏覽器不支援背景模糊時，會使用不透明表面。內建色盤會針對明亮與深色圖片調整文字；自訂 CSS 仍可覆寫對比。懸停、鍵盤焦點與按壓均有操作回饋，減少動態效果偏好會停用動畫；版面也會適應窄螢幕與阿拉伯文 RTL。

**複製並自訂**會複製顏色、圓角與陰影，不會複製版面。未來玻璃的強調色欄位保留既有安裝的行為；若要調整其他色盤，請先複製再自訂。舊版已儲存外觀會保留先前對應的版面，直到自行改選。控制項、卡片、對話框、選單與通知共用語意色彩與系統字型。

## 個人瀏覽器與站台預設

- **主題風格 → 在此瀏覽器使用**會儲存個人風格／自訂定義及 CSS。個人風格會整組取代站台的色彩與 CSS，不會在另一套個人風格上悄悄疊加站台 CSS。
- **使用站台外觀**只移除個人風格，不會刪除已儲存的主題庫，也不會變更獨立選擇的深淺模式。
- 太陽／月亮選單中的**使用站台主題**只移除本機深色／淺色／系統覆寫。**系統**表示跟隨作業系統，而非跟隨站台設定。
- **管理 → 外觀 → 儲存變更**會設定未選擇個人風格的瀏覽器所使用的共用預設。只有已登入管理員可儲存共用設定，仍須通過 Origin、CSRF 與修訂版本檢查；發生衝突時會保留草稿，直到明確重新載入。
- 首次造訪私人站台時，會先使用內建外觀，直到登入後可取得 bootstrap 設定。曾使用的瀏覽器可能在登入前套用快取的外觀，但快取不包含帳戶、工作階段或服務目錄。

本機只保存外觀偏好：語系、深淺模式、快取的共用外觀、個人外觀、個人背景圖片及已儲存的色彩主題庫。自訂主題名稱／CSS 是外觀內容，不可放入密碼、權杖、私人服務位址或其他機密。共用外觀會進入可攜式備份，個人選擇與瀏覽器主題庫則不會。

## 背景圖片

- 在**主題風格**中選擇個人圖片、**不使用背景圖片**或**使用站台背景**，再按**在此瀏覽器使用**儲存。圖片存於此瀏覽器的 IndexedDB，不會上傳伺服器，也不包含於站台備份。清除站台資料或瀏覽器回收空間時可能移除圖片，請另外保留原始檔。**使用站台外觀**會移除個人選擇及其已儲存圖片。儲存或清理失敗時會顯示提示；清除此站台的瀏覽器資料也會移除其他本機偏好。
- 管理員可在**管理 → 外觀**選擇或移除共用圖片，並與其他草稿一併儲存。公開站台的訪客可存取該圖片；私人站台則需登入。完整備份包含共用圖片；未包含圖片的匯出若仍參照缺少的背景或圖示，便無法還原。
- 兩者均支援 PNG、JPEG 或 WebP，最大 **4 MiB**、每邊最多 **4096 像素**、總計最多 **8,847,360 像素**；不接受 SVG 或遠端圖片網址。共用 PNG／JPEG 會解碼後重新編碼；JPEG 會套用方向並移除中繼資料。共用 WebP 與個人圖片可能保留中繼資料，選擇前請先移除敏感中繼資料。正規化後的共用檔案也必須符合大小上限。
- **在頁面預覽**只會暫時套用草稿圖片；**Escape** 可還原目前外觀而不儲存。`/?appearance=safe` 不會顯示或請求圖片，也不會刪除圖片或繞過存取控制。

## 建立與保存自訂主題

1. 選擇內建風格，再按**複製並自訂**（Customize a copy）。內建風格不可覆寫。
2. 命名，分別編輯**淺色**與**深色**的背景、表面及強調色，並選擇基礎圓角及無／柔和陰影。文字、次要文字、控制項邊框與焦點顏色會自動推導；無法共用易讀文字顏色的表面組合會被拒絕。
3. 比較兩個啟動器範例。**在頁面預覽**（Preview on page）只會暫時套用所選預覽模式與 CSS，不會儲存。**停止預覽**或 **Escape** 可還原目前外觀；Escape 會保留開啟中的編輯草稿。編輯已預覽的值也會停止該次預覽。
4. **儲存至此瀏覽器的主題庫**會明確儲存可重用的色彩副本，最多 **10** 套。載入主題庫項目只會編輯草稿；**更新已儲存的主題**則更新該特定副本。刪除須經確認，且不會改變已套用的外觀。
5. 最後按**在此瀏覽器使用**，或管理員的**儲存變更**。儲存主題庫是獨立操作，不會因取消外觀草稿而復原；套用個人主題也不會自動新增主題庫副本。

匯入主題 JSON 後須先檢視，再按**使用匯入的主題**填入草稿，不會自動套用或儲存。無效 UTF-8、重複／未知欄位、不支援的格式值或過大檔案會被拒絕。儲存空間失敗時會保留草稿，不會回報儲存成功。

## 色彩主題 JSON 格式

獨立的 UTF-8 JSON 檔案最多 **16 KiB**，包含空白字元。它只包含色彩設定，不含 CSS、服務資料或遠端網址。匯出檔名為 `nexa-home-theme.json`。

```json
{
  "schemaVersion": 1,
  "name": "My Tide",
  "variants": {
    "light": {
      "background": "#F0F7F8",
      "surface": "#FFFFFF",
      "accent": "#006C73"
    },
    "dark": {
      "background": "#0C1B22",
      "surface": "#132D38",
      "accent": "#6BD3CC"
    }
  },
  "radius": 16,
  "shadow": "soft"
}
```

使用 `schemaVersion: 1`、不含控制字元且非空白的 1–80 個 Unicode 字元名稱、六位十六進位色碼，`radius` 為 `8`、`12`、`16` 或 `20`，`shadow` 為 `none` 或 `soft`。深淺兩個版本皆為必填。背景與表面必須可共用對比至少 **4.5:1** 的黑色或白色文字，其餘文字／控制項／焦點色彩會依對比需求推導。基礎圓角會按比例套用至控制項／卡片／面板，而非讓所有元件形狀完全相同。

## 開放任意 CSS

在任一外觀編輯器展開**進階 CSS**。這是刻意開放的 CSS 選項，而非選擇器／屬性允許清單：接受一般選擇器、偽類別、自訂屬性、`@media`、`@supports`、`@layer` 及瀏覽器支援的其他 CSS 規則。無效 CSS 仍保留為原始文字，由瀏覽器忽略；這不是 JavaScript 或 HTML 編輯器。

原始 CSS 是獨立的 UTF-8 欄位／檔案，最多 **64 KiB 位元組**，不可含 NUL。**匯入 CSS 檔案 → 使用匯入的 CSS**只會填入草稿，預覽／儲存仍須明確操作。匯出檔名為 `nexa-home-theme.css`。CSS 不會包含在色彩 JSON 或主題庫副本內；站台共用 CSS 則會包含於站台備份。

例如，在不取代色盤的情況下加入卡片虛線邊界：

```css
@layer personal {
  @media (min-width: 640px) {
    .service-tile {
      border: 1px dashed var(--accent-ink) !important;
    }
  }
}
```

覆寫圖層中的 `!important` 是刻意使用的：否則，一般未分層的應用程式規則會優先於一般分層規則。自動產生的根元素色彩是行內屬性，若要覆寫相同屬性，也須使用 `!important`。類別名稱／HTML 結構可能隨版本變更，升級後應重新檢查自訂 CSS。

**必須信任 CSS 的作者。** CSS 可能隱藏控制項、遮住警告、改變互動區域，或破壞對比／RTL／減少動態效果。色彩對比檢查不代表任意 CSS 已通過無障礙驗證。請勿套用未審查的 CSS，或在其中放入機密。共用樣式表會以外觀內容送至獲准存取站台的瀏覽器，不是機密儲存空間。

CSS 使用獨立的 `style` 元素，帶有目前 HTML 回應的 nonce，並以文字插入，絕不插入 HTML。關閉 style／script 的文字無法建立 script 元素。CSP 不會被放寬：指令碼仍限同源，不允許行內／eval 執行，外部 CSS 匯入、字型與圖片仍被阻擋。既有同源與獲准的 data／blob 圖片規則仍適用。伺服器不會擷取 CSS 網址。請勿為了讓遠端匯入運作而停用 CSP 或 TLS 檢查。

## 復原無法使用的外觀

- 預覽期間按 **Escape**，即可還原先前外觀而不儲存，即使預覽隱藏整個頁面也一樣。
- 若樣式已儲存，請在相同 Origin 開啟 **`/?appearance=safe`**，也可使用 **`/admin/appearance?appearance=safe`**。安全外觀會在首次繪製前，使用不透明表面的未來玻璃，並停用自訂色彩、CSS 與背景圖片。在同一份已載入文件內持續有效，即使內部連結移除了查詢參數也一樣。
- 安全外觀不會刪除已儲存設定、重設密碼、建立工作階段，或授予私人／管理資料存取權。原有登入要求不變；請正常登入後修復共用設定，或選擇個人風格覆寫共用外觀。
- 儲存修復後的草稿，再按**離開安全外觀**，重新載入不含復原模式的頁面。只透過用戶端導覽變更位址，不會停用復原模式；不需要刪除資料目錄或資料卷。

## API、備份與升級相容性

[OpenAPI 契約](../../api/openapi.yaml)中的 `theme` 維持為 `dark | light | system`；`themePreset` 與 `layoutPreset` 彼此獨立，可為 null 的 `customTheme` 與 `customCSS` 承載風格。更新仍使用 `expectedRevision`；省略舊版風格擴充或 `layoutPreset` 時，會保留目前值。省略 `backgroundUpload` 會保留共用圖片，傳送 `null` 會移除，或提供標準 base64 於同一交易中取代。`backgroundImage` 是僅供回應的雜湊值，不是上傳欄位。完整 16 MiB 可攜式預算包含 JSON 跳脫，以及圖示／背景 base64 的精確展開；超限寫入會回傳 `409 LIMIT_EXCEEDED`，不會部分寫入。

目前的可攜式匯出使用**備份版本 4**，包含共用版面、背景圖片、色彩／CSS 與可選的健康檢查設定。仍支援匯入**版本 1–3**；版本 1 與 2 不包含健康檢查，較舊風格會保留原本對應的版面。版本 1 缺少風格擴充時，使用未來玻璃且不套用自訂 CSS。不能只修改版本標記，就讓舊應用程式還原版本 4。主題 JSON 格式 1、備份版本 4 與資料庫結構版本 4 是不同的版本編號。

資料庫遷移 `002_themes.sql` 只新增欄位，不修改初始遷移、既有偏好、修訂版本、憑證、工作階段、稽核或速率限制狀態；`003_service_health.sql` 加入可選監控功能，`004_appearance.sql` 加入獨立版面與共用背景儲存。目前的建置將既有結構版本 1、2 或 3 升至 4 前，啟動流程會依起始版本建立私有且已 fsync 的 **`nexa.pre-migration-v1-to-v4.db`**、**`nexa.pre-migration-v2-to-v4.db`** 或 **`nexa.pre-migration-v3-to-v4.db`**，包含已提交的 WAL 與驗證狀態。較早建置則使用各自目的版本的快照名稱。全新安裝不會建立此快照；`doctor` 會以唯讀方式開啟既有、受支援的結構，絕不執行升級。未來或無效結構會在變更 journal 前被拒絕。

資料卷內快照含有敏感驗證狀態，**不是**卷外備份，也不是完整圖示封存檔。如果升級尚未完成，但該快照名稱已存在，啟動會拒絕繼續，而非覆寫它或在每次重啟時再建立副本。請先停止服務、檢查失敗原因，將該確切檔案保留／移至私有備份空間，解決原因後才重試。不可移除或覆寫唯一的復原副本。升級前仍須建立一般的停機完整備份；跨越結構版本 2、3 或 4 回復舊版，必須使用升級前資料與相容的舊執行檔。詳見[備份與復原](backup-and-recovery.md)。
