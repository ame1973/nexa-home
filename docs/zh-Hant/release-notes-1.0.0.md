# Nexa Home 1.0.0 版本說明

[English](../release-notes-1.0.0.md) | **繁體中文**

**狀態：1.0.0 實作與本機部署驗證已完成。** 本說明不代表已發布登錄檔映像／版本標籤，或已成功執行託管 CI。請從經審查的原始碼工作目錄建置。下述未使用的 OpenPGP 模組公告，具有經審查、附條件且會到期的例外；並未隱藏或宣稱該公告不存在。

## 本版本提供的功能

Nexa Home 是單一管理員、自行架設的服務啟動器，使用 Go／SQLite 執行環境與內嵌 React 前端。支援公開／私人可見性、本機搜尋、我的最愛、分類／標籤、無障礙手動排序、本機圖示上傳、外觀設定，以及經驗證的可攜式備份／還原。初版介面提供繁體中文與英文，以及深色、淺色與系統主題。後續新增語系與阿拉伯文 RTL，請見[尚未發行變更](../../CHANGELOG.zh-Hant.md#尚未發行)及[目前介面語言說明](../../readme.zh-Hant.md#介面語言)。

支援目標為 Linux amd64 與 arm64。同一資料目錄只屬於一個程序。Docker 為選用；原生執行檔不需要 Node 執行環境。容器使用固定的非 root UID／GID `10001:10001`、唯讀根檔案系統與私有持久性 `/data`。信任邊界包含主機／Docker 管理員與資料擁有者。

## 首次安裝

1. 依照[部署文件](deployment.md)選擇私有本機儲存空間，並設定精確的公開 Origin。
2. 遠端存取使用 HTTPS。提供的 Compose 預設只綁定回送位址；刻意隔離的 HTTP 安裝需要明確的 Cookie 例外。
3. 在本機讀取會到期的設定權杖、初始化管理員並登入。請勿公開啟動日誌或權杖。
4. 新增服務，分享啟動器前先檢查可見性／私人模式。
5. 匯出含圖示的完整可攜式備份，並在獨立儲存空間測試復原。

沒有預設密碼、匯入的示範服務目錄、背景服務探測、遠端網站圖示下載或遙測。LAN／WAN 連結不會啟用自動切換；啟動器只開啟主要網址。

## 資料與相容性

- 初始 SQL 結構版本為 1。未來遷移只向前進行；遇到未知新版結構會拒絕通過，請勿強制降級。
- 可攜式格式為 `nexa-home-backup`，版本 1。完整匯出包含組態與圖示內容，不包含管理員憑證、工作階段、速率限制狀態或稽核歷程。
- 還原會取代組態，並保留目的端驗證／稽核狀態。匯入外觀可能改變公開／私人存取，因此請檢查預覽。權杖五分鐘後到期，且即使提交失敗也只能使用一次。
- 完整可還原匯出最多 **16 MiB，包含 base64**。服務、分類、標籤各最多 5000 筆；圖示最多 1024 個、每個 1 MiB、點陣圖尺寸 512 × 512；排序位置為非負 32 位元有號整數。
- 公開檢視會省略隱藏服務／隱藏分類的子服務，以及未使用的分類／標籤。刪除分類會保留其服務並移至「未分類」，個別設為可見的服務可能在該處公開。
- 此應用程式不是分散式 SQLite 服務。不支援使用中的共用 NAS 掛載、多寫入者、Docker socket、特權模式與公開 HTTP 部署。

升級或主機遷移前，請同時保留可攜式匯出，以及停機後的完整資料備份與其精確相容的軟體版本。詳見[備份、版本回復與復原](backup-and-recovery.md)。完整封存檔會保留舊登入憑證；新管理員搭配可攜式匯入，才是支援的憑證遺失復原方式。

## 安全檢查與已知公告

鎖定的最新穩定版 `golang.org/x/crypto v0.58.0` 包含針對不再維護 OpenPGP 套件的 [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932)。Nexa Home 使用 Argon2id／BLAKE2b，不使用 OpenPGP。原始碼與保留符號的二進位可達性分析，和映像的模組層級發現是不同的檢查。

涵蓋所有嚴重程度的 Trivy 掃描，會將此模組公告保留為經審查的抑制項目。規則只比對 `GO-2026-5932`、執行檔 `nexa-home` 與精確的 x/crypto v0.58.0 PURL，於 **2027-02-01** 到期，而且僅在沒有直接或轉移執行期依賴使用 OpenPGP 時才有效。原始碼／實際執行檔分析不抑制此公告，CI 會拒絕 OpenPGP 匯入。路徑／版本／公告不同或政策到期時均不相符，所有未處理發現仍會使檢查失敗。重新評估要求請見[安全說明](../../SECURITY.zh-Hant.md)；沒有依嚴重程度整批略過、忽略未修補項目或移除中繼資料的做法。
